# Examples

These examples use files that ship in this repository, and each one says what it needs.

| Example | What it shows | Needs a model? |
|---|---|---|
| [Fix a failing test](./fix-a-failing-test.md) | The agent reads a failing test, edits the code, and the tests pass | Yes |
| [Read a policy decision](../overview/getting-started.md#2-see-a-policy-decision) | How one tool call is allowed or blocked, and why | No |
| [Read a loop refusal](../concepts/tasks-and-loops.md#what-a-refusal-looks-like) | What the agent sees when it repeats an edit too many times | No |

The first example uses the sample project in `examples/toy-python-repo`. The other two need only the `agent` binary.
